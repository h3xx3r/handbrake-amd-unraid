# AMD Radeon RX 6700

Die Radeon RX 6700 basiert auf RDNA2 / Navi 22 und besitzt AMD VCN für
Hardware-Videoverarbeitung.

Für dieses Container-Projekt werden unter Linux die offenen Kernel-/Mesa-
Komponenten verwendet:

```text
Host-Kernel: amdgpu
Container:   Mesa radeonsi + libva
Device:      /dev/dri/renderD128
```

Es muss kein proprietärer AMD-Grafiktreiber im Unraid-Host installiert werden.
Der Container greift über `/dev/dri` auf den bereits vom Host bereitgestellten
DRM-Render-Node zu.

## Empfohlene Variablen

```text
LIBVA_DRIVER_NAME=radeonsi
VAAPI_DEVICE=/dev/dri/renderD128
```

## Fehler: kein VAAPI-Encoder sichtbar

Zuerst prüfen:

```bash
ls -la /dev/dri
```

Dann im Container:

```bash
vainfo --display drm --device /dev/dri/renderD128
```

Falls mehrere Grafikkarten vorhanden sind:

```bash
vainfo --display drm --device /dev/dri/renderD129
```

Den funktionierenden Render-Node anschließend in `VAAPI_DEVICE` eintragen.
